# Telegram Bot Project

Цей проект — Telegram-бот, створений за допомогою `grammY` та `TypeScript`.

## Як запустити

1. Отримайте токен бота у [@BotFather](https://t.me/BotFather).
2. Відкрийте файл `.env` та замініть `YOUR_TELEGRAM_BOT_TOKEN_HERE` на ваш токен.
3. Встановіть залежності (якщо ви копіюєте проект):
   ```bash
   npm install
   ```
4. Запустіть бота:
   ```bash
   npm start
   ```

## Команди
- `/start` — Привітальне повідомлення.
- `/help` — Список доступних команд.
- `/about` — Інформація про бота.

## Функції
- Відповідає на вітання ("привіт", "hello").
- Підказує використати `/help`, якщо написати "help" без слеша.
- Робить випадкові компліменти! ✨
